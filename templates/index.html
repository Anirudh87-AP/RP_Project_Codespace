Project Summary

This project bridges the gap between theoretical Random Process mathematics and real-world telecommunications. By actively mitigating Additive White Gaussian Noise (AWGN) in digital channels—such as VoIP, video conferencing, and mobile networks—we apply rigorous mathematical frameworks to recover degraded audio arrays and extract semantic intelligence. Aligning with UN Sustainable Development Goals (SDGs 3, 4, 9, and 10), our system provides an interactive, full-stack digital signal processing environment designed to ensure accessible, reliable, and intelligent communication.

Theoretical Framework: Random Process Signal Flow

The mathematical modelling of this system follows the classical communication channel theory, where a pure message signal is corrupted by stochastic noise and subsequently recovered using digital signal processing techniques rooted in Wide-Sense Stationary (WSS) and ergodic random process methodologies.

📡

1. Transmitter (Modulated Output)

s(t) = [1 + μ · m(t)] · cos(ka · fc · t)

The pure modulated signal s(t) is generated using Amplitude Modulation (AM) with modulation index μ = 0.85 and frequency constant ka = 2π. The message signal m(t) is a composite multi-tone waveform simulating the harmonic structure of human speech across formant frequencies (150 Hz, 400 Hz, 900 Hz, 2500 Hz, 3200 Hz).

▼
📶

2. The Channel (AWGN)

n(t) ~ N(0, σ²)

The communication channel introduces stochastic Additive White Gaussian Noise n(t), drawn from a zero-mean Gaussian distribution. The noise power σ² is calibrated to achieve a specific Signal-to-Noise Ratio (SNR) relative to the signal power: Pnoise = Psignal / 10(SNR/10). This models real-world degradation in VoIP, mobile networks, and video conferencing scenarios.

▼
📻

3. Receiver (Demodulator Input)

x(t) = s(t) + n(t)

The corrupted signal x(t) is the superposition of the desired signal s(t) and the stochastic noise n(t). This is the actual audio that arrives at the receiver — degraded, noisy, and challenging for both human listeners and ASR engines to interpret. The input x(t) array forms the basis for all downstream processing.

▼
⚙️

4. Processing (Demodulator Output)

y(t) = HButterworth(x(t))

Wide-Sense Stationary and ergodic random process methodologies are applied via a 4th-order Butterworth digital low-pass filter to extract the signal envelope from x(t). The Butterworth filter provides a maximally-flat magnitude response in the passband with a roll-off of −80 dB/decade, implemented using Second-Order Sections (SOS) for numerical stability and zero-phase forward-backward filtering (sosfiltfilt) to eliminate phase distortion. The result is the enhanced output y(t).

📐

Mathematical Formula Reference

Core mathematical expressions governing the Random Process analysis and Analog Communication signal processing pipeline.

Autocorrelation Function (WSS)

Rxx(τ) = E[X(t) · X(t + τ)]

Measures signal self-similarity across time lag τ. For a WSS process, Rxx depends only on the lag, not absolute time.

Power Spectral Density (Wiener-Khinchin)

Sxx(f) = ℱ{Rxx(τ)} = ∫ Rxx(τ) · e−j2πfτ dτ

The PSD is the Fourier transform of the autocorrelation — decomposes signal power into frequency components.

Butterworth Filter Transfer Function

|H(jΩ)|² = 1 / [1 + (Ω / Ωc)2N]

Maximally-flat magnitude response. N = 4 (filter order), Ωc = 4000 Hz (cutoff). Roll-off: −80 dB/decade.

Signal-to-Noise Ratio (dB)

SNRdB = 10 · log10(Psignal / Pnoise)

Quantifies signal quality. Psignal = mean(s²(t)), Pnoise = mean(n²(t)). Higher SNR = cleaner signal.

Mean Square Error

MSE = (1/N) · Σi=1N [s(i) − y(i)]²

Measures reconstruction accuracy between original s(t) and recovered y(t). Lower MSE = better enhancement.

Amplitude Modulation (DSB-FC)

sAM(t) = Ac[1 + μ · m(t)] · cos(2πfct)

Double-sideband full-carrier modulation. μ = 0.85 (modulation index), fc = carrier frequency, m(t) = message signal.

AWGN Power Calibration

σ² = Psignal / 10(SNRdB/10)

Computes noise variance to achieve a target SNR. Ensures reproducible, calibrated noise injection for testing.

Ergodic Process Condition

⟨X(t)⟩T = E[X(t)] as T → ∞

Time-average equals ensemble average. Allows statistical inference from a single realisation of the random process.
